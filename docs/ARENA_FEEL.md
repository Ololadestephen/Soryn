## Implemented behavior

Setup offers Ruined Sanctuary, Moonlit Grove, Ember Foundry and Sky Temple thumbnails, plus Random. The server resolves Random once inside match creation, using a separate cosmetic random choice. Optional `arena` and `arenaChoice` fields live outside the frozen combat snapshot. Missing legacy metadata reads as Sanctuary, without rewriting old records. Retry validates the original selection, refresh/history retain the result, and rematch retains the actual environment rather than rerolling Random. Integration tests compare whole battles across all four choices for identical authoritative states and rounds.

The portrait field now starts directly below the measured HUD, with a compact height around the source-capped fighters. Feet and companions retain their shared ground anchor. Real HUD/control sizes drive framing, including enlarged text. Figure size never exceeds the existing logical source canvas; the camera repositioning does not create new image detail. Desktop and landscape retain separated opponents. Controls reserve label/status space so resource and cooldown changes do not move the button row. Safe-area padding is applied to HUD, settings and controls.

Playback sequences anticipation, action/contact, impact/reaction and recovery. Ordinary contacts pause figure animations for 40 ms and use a 1.5 px field shake; specials use 65 ms and 3 px. Contact rings and four small special sparks follow the affected fighter. Guard, block, counter, healing, energy recovery, multi-hit and knockout are derived from authoritative events. Cancelled attacks have no successful contact cue. Defeated artwork holds through results and refresh. Reduced motion removes hit-stop, shake and moving sparks, retaining clear static feedback. Input is locked during loading/resolution, and existing focus restoration remains. Current move notices replace/deduplicate, expire within three seconds and clear at completion. History stays optional after the match.

Sound starts only after selection, confirmation or an explicit sound-control interaction. Settings and setup provide an effects toggle, volume and Try sound; bounded preferences persist locally. The app loads common cues and the two selected families only after activation. Actual impacts, guard/counter, healing, energy, twelve distinct specials, knockout and result cues have typed event mappings and duplicate guards. Refresh does not replay a completed match's sounds. Missing audio cannot block combat. There is no music in this milestone.

## Assets, provenance and costs

The sanctuary uses the existing approved environment master. Three new empty environments were created with the available built-in image generation tool from original descriptions matching the lavender/gold sculpted world. Exact prompts, tool outputs and copied master paths are recorded in [image provenance](evidence/arena-feel/image-provenance.json). No NFT/Kuroro artwork was copied. This establishes how these project assets were made, not a separately confirmed license to Chog collection artwork.

All twenty-four effects are original deterministic procedural synthesis: authored tones and seeded noise, no third-party recordings or samples, no paid service. `scripts/audio/prepare.py` reproduces 44.1 kHz mono 16-bit PCM WAV files. No external recording license is required; no public license is assigned to the wider project. [Audio measurements](evidence/arena-feel/audio.json) record every cue. Full palette: **532,462 bytes**, **1,062,812 bytes estimated decoded Float32 samples**; individual duration 55–500 ms. Only twelve common cues plus the matchup's distinct specials are prepared.

`scripts/prepare-arena-backgrounds.mjs` creates quality-90 WebP desktop and efficiently cropped portrait variants, plus 240×160 setup thumbnails. The masters are preserved; runtime backgrounds are not upscaled during export. [Background dimensions/bytes](evidence/arena-feel/backgrounds.json):
