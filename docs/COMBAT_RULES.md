## Shared frozen rules

`combat-rules/1`, `combat-fighters/1`, `combat-moves/1` remain unchanged. New first-party starts explicitly choose Easy/Medium/Hard and freeze `combat-opponent/2` plus the typed difficulty. Existing `/1` battles and compatibility starts without a difficulty retain their original `combat-opponent/1`, explicitly labelled **Legacy policy**; they never acquire an invented Medium field. Exact policy/distribution/scoring, validation and benchmark evidence: [COMBAT_PRESENTATION.md](COMBAT_PRESENTATION.md). Each battle freezes both full definition snapshots, initial resources and the fixed initial tie identity 0 (the resolver also supports frozen identity 1). No misses, crits or RNG. New server battles always use tie identity 0. Definitions are original application classes, never collection traits. Two NFTs or rarity never stack power.

Energy cap 6, initially 4; basic costs 1, guard 0, special as listed. Recover 2 at end of every ongoing round while alive, capped at 6. Special cooldown C means C whole following rounds unavailable: use R1 with C2 → unavailable R2/R3 → usable R4. Maximum 20 rounds. On round 20, surviving fighters draw regardless of health; deliberate defence/heal loops cannot extend a match.

Both choices spend energy and set special cooldown when locked, even if later knocked out. Defences and Aegis special shields prepare before initiative, for both fighters, so slower defence still works. Guard does not attack. Initiative = base speed + move bonus + applicable passive. Ties alternate player-first/opponent-first using `(round + tie) % 2`; this is reproducible, not random fairness.

For each hit: apply eligible dodge first (Nyx guard intercepts one basic only), then Echo decoy absorbs up to 6, then armour (reduced by 3 while exposed, minimum zero; Nyx special pierces 2), then prepared shield (exposed reduces its initial capacity by 4), then health. Shield/decoy are shared across multiple hits and never go negative. Damage minimum zero; no random hit or crit. Aegis guard's counter triggers once after a damaging guarded hit for 4 raw damage mitigated by armour only (ignores shield/decoy/dodge), without recursive counter triggers. If either fighter reaches zero, its unexecuted attack is cancelled; cancelled actions receive no attack animation. Self-damage after Ember's burst can produce a simultaneous knockout draw.

After both actions: resolve both living fighters' burn simultaneously (3 damage), then knockout; ongoing-match survivors receive guard/passive recovery, energy and cooldown progression. Terminal battles stop recovery. Both burn knockouts draw. No resurrection. Effects applied this round retain their declared future duration; old durations decrease once at round end. Shield/dodge/guard-created decoy expire at round end. Exposed/disrupt/burn never stack: reapply refreshes to the maximum remaining duration. Disrupt bans special next round only, never cancels an already locked legal special. Counter cap one; healing cannot exceed initial health.

Opponent is selected and stored from pre-round public health/energy/cooldowns/effects plus completed round choices before accepting the player choice. It receives no current player choice, actor, token, private history or future state. Pending move and reason remain server-only until resolved. Different fighters' policy preferences are deterministic; explanations appear only after reveal. No machine-learning or cryptographic-fairness claims.

## Access, persistence and presentation

Guest can choose four starters; computers can use any class as game content. Official mode uses existing Privy proof + cookie/session linked wallet + fresh owner/generation checks on every write, including repeat requests. One grant never stacks stats. Battle histories are private by default; no automatic combat publication or NFT metadata modification. Former owners cannot advance their old official match; private history stays with its author. Existing public adventure consent controls stay intact.

Separate SQLite battles table, actor-scoped private reads, frozen snapshots, accepted choices, deterministic round event frames, pending opponent and optional authority. Start IDs are idempotent for identical inputs; round requests include ordinal and action. Same completed ordinal/action returns the authoritative result; conflicting/stale/future ordinal fails. A terminal match rejects new choices. Rematch is a new record, never a health reset of an old battle. Snapshot reads verify deterministic reconstruction, including pending opponent policy.

Server returns public state, legal actions, completed choices/explanation and authoritative presentation events, never pending opponent. Events carry health/energy/effects frames: prepare, approach/projectile, impact/reaction, return, heal, status, counter, cancel, knockout, recovery/result. UI health changes on its corresponding frame. UI timers animate only returned events and lock all move controls through the sequence. Refresh skips animation to authoritative final state; reduced motion shortens it. No pretend-thinking delay.

All twelve use newly authored tall full-body layered SVG geometry, distinctive equipment/limbs/postures. No borrowed NFT/Kuroro art. Combat animation is event-bound CSS/SVG movement/effects, not concept art or sprite animation.
