# Déjà Vu — complete experience rebrand

Implemented locally October 14, 2026 at http://127.0.0.1:3000/. [Palette, typography, components, reference inspection and asset provenance](GAME_IDENTITY.md). This supersedes the earlier cream/editorial presentation; the approved rendered fighter/companion artwork and arena worlds are retained.

## Delivered

Original accented vector wordmark and memory seal, compact shared navigation/footer, midnight/charcoal surfaces, gold actions, ivory text, consistent focus and labelled selection/error states. Secondary pages have concise destination titles. The landing order is identity/Play → actual gameplay → twelve-fighter selection → four arenas → holder benefits → additional adventures and final Play. The hero remains arena-only, with no character cutouts, curtains, parallax, mandatory intro or decorative arrows.

The gameplay showcase is a real isolated guest Pip/Owl versus computer Bolt/Cheetah battle. It shows a defensive response, basic attack, companion special, resulting resource changes and victory after eight rounds. It has a lightweight poster, explicit Play, native controls, Close with focus restoration, failure/retry and a working battle link. The video mounts only after interaction; playback pauses offscreen or when the document is hidden. Captions explain the sequence. It is silent and is not live-holder validation, PvP, a fabricated HUD or a rendered promotional simulation.

The roster prioritises artwork, name, role, companion and concise kit summaries; exact versioned damage/energy/cooldown/passive rules remain in native ability disclosures. All twelve selectors and working special previews remain. Setup shows the selected pair, opponent/difficulty, real arena choices and the existing Start/Resume actions. Difficulty copy describes the implemented policies without claims about human difficulty ordering. Selection reflows to one column on narrow phones, including enlarged text.

Full-screen combat keeps the existing native dialog, measured field geometry, approved artwork, server event sequence, health/resource updates, three-second replacing latest-move notice, reduced motion and settings. Result prioritises outcome and Rematch, with Change setup and intentional history access. Shared dark panels also cover private history, identity, journal, museum, adventure, challenges and recovery states. No invented rewards or progression.

Wallet/ownership copy is shorter and actionable. Grant/ownership/provider failures never become verified-holder success styling. Exact token IDs remain required, and public adventure/private battle history are described distinctly. Technical policy digests are kept in optional ghost details; ordinary flows no longer lead with internal write/RPC/renderer language. Wallet connection and signing remain explicit player actions.

No domain rules, server calculations, policy versions, auth gates, database schemas, API contracts or existing URLs were changed. The one identity error helper only translates displayed messages. User saved battles were not used to obtain footage: automation uses the existing isolated SQLite, synthetic RPC/JWT and disposable browser identities. Original art exports, legacy fallbacks, Blender sources and unrelated historical evidence remain preserved. No dependencies, external fonts, paid services, transactions, commits, pushes or deployments.
